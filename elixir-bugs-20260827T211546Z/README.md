# Elixir Bugfix Scan — Ranked Summary

Scan folder: `elixir-bugs-20260827T211546Z` (Elixir 1.21.0-dev / OTP 29, tree `3389f8405`). No `VALIDATION.md` was present; per-file reports carry their own `verified`/`asserted` evidence verdicts, and cross-file/cluster findings were weighed first per the priority order. Overlapping cluster⇄per-file findings are merged and reported once. All findings below are surviving (not dropped/ruled-out); dismissals and coverage-gap ledger rows are excluded.

## Tier 1 — Critical / High (verified, real code defects)

1. **Bitstring size-expression calls dropped by the type checker — valid macros become fatal `CompileError`** · `lib/module/types/traverse.ex` · [`CSCAN-traverse-bitstring-specifier-calls-dropped`](./lib-module-types-traverse.ex.md#cscan-traverse-bitstring-specifier-calls-dropped) · **Critical**, high, verified. `of_expr` never traverses the *specifier* side of a bitstring segment, so a local function used inside a size expression (e.g. `<<x::size(helper())>>`) is seen as never-called. On the `:traverse` path that every macro compilation uses, this misclassifies correct code and aborts with `undefined function`. Broadest blast radius of the scan.

2. **`Inspect` for `HashDict`/`HashSet` splices a `{doc, opts}` two-tuple into `concat` → `FunctionClauseError`** · cross-file (`hash_dict.ex`/`hash_set.ex` ⇄ `inspect.ex` ⇄ `inspect/algebra.ex`) · [`CSCAN-cluster-inspect-list-two-tuple-return`](./CLUSTER_lib-2.md#cscan-cluster-inspect-list-two-tuple-return) · **High**, high. `Inspect.List.inspect/2` returns a two-tuple for non-empty lists, but both impls feed that straight into `concat/1`, which rejects the tuple — every non-empty `HashDict`/`HashSet` crashes on inspect. Only visible by reading the three files together.

3. **`HashDict` protocol atoms missing the `Elixir.` prefix → all ops crash** · `lib/hash_dict.ex` · [`CSCAN-hash_dict-protocol-module-atom-missing-elixir-prefix`](./lib-hash_dict.ex.md#cscan-hash_dict-protocol-module-atom-missing-elixir-prefix) · **High**, high, verified. Impls build `:HashDict` instead of `:"Elixir.HashDict"`, so every `Enumerable`/`Collectable`/`Inspect` operation raises `UndefinedFunctionError`.

4. **`HashSet` same missing-`Elixir.`-prefix defect** · `lib/hash_set.ex` · [`CSCAN-hash_set-unsafe-atom-missing-elixir-prefix`](./lib-hash_set.ex.md#cscan-hash_set-unsafe-atom-missing-elixir-prefix) · **High**, high, verified. All `Enum`/`Stream`/`into`/`inspect` operations on a `HashSet` crash with `UndefinedFunctionError`. (Findings 2–4 together mean these two legacy collections are effectively non-functional.)

5. **`Registry.lock/3` uses the default 5 s `GenServer.call` timeout instead of `:infinity`** · `lib/registry.ex:1854` · [`CSCAN-registry-lock-call-timeout`](./lib-registry.ex.md#cscan-registry-lock-call-timeout) · **High**, high, verified (reproduced). Any contender waiting on a critical section that runs longer than 5 s crashes with a `:timeout` exit — the lock silently fails under exactly the contention it exists to serialize.

6. **Malformed bitstring size/unit spec → raw `MatchError`** · `elixir_bitstring.erl` · [`CSCAN-elixir_bitstring-build-spec-empty-badmatch`](./elixir_bitstring.erl.md#cscan-elixir_bitstring-build-spec-empty-badmatch) · **High**, high, verified (executed). An invalid integer/float spec (e.g. `<<1.0::float-size(8)>>`) makes `build_spec` return `[]`, hitting an unguarded `[H|T] =` match; the internal crash truncates the rest of the compiler's error reporting after the clean diagnostic.

7. **Unclosed inline `<!--` crashes `IO.ANSI.Docs.print/3` (IEx `h`)** · `lib/io/ansi/docs.ex` · [`CSCAN-docs-inline-comment-matcherror`](./lib-io-ansi-docs.ex.md#cscan-docs-inline-comment-matcherror) · **High**, high, verified. `drop_comment/1` assumes a 2-element split, so malformed markdown in a docstring crashes `h Mod` with a `MatchError` instead of rendering.

8. **`Code.Fragment.container_cursor_to_quoted/2` silently drops `:file`/`:line`/`:column`** · `lib/code/fragment.ex` · [`CSCAN-fragment-cctq-drops-file-line-column-opts`](./lib-code-fragment.ex.md#cscan-fragment-cctq-drops-file-line-column-opts) · **High**, high, verified. Documented positioning options are stripped before use, so returned AST is always anchored at line 1 / column 1 — breaks tooling that relies on real positions.

9. **`scripts/diff.exs` crashes on any nested build tree** · [`CSCAN-diff-file-dir-relative-path`](./scripts-diff.exs.md#cscan-diff-file-dir-relative-path) · **High**, high, verified. `compare_dirs/2` calls `File.dir?/1` on paths resolved against cwd rather than `dir1`, so subdirectory entries survive the reject and crash with `File.Error :eisdir`. Dev/release tooling, not shipped runtime.

## Tier 2 — Medium (verified)

10. **Repeated literal map key in a *match* aborts the whole compile instead of taint-and-continue** · cross-file (`elixir_map.erl:96` ⇄ `elixir_errors.erl`) · [`CSCAN-cluster-map-repeated-key-passes-file-not-env`](./CLUSTER_root-3.md#cscan-cluster-map-repeated-key-passes-file-not-env) / [`CSCAN-elixir_map-repeated-key-passes-file-not-env`](./elixir_map.erl.md#cscan-elixir_map-repeated-key-passes-file-not-env) · **Medium**, high, verified. The call passes the file binary instead of env `E`, converting a recoverable `function_error` into a fatal, immediately-raising `file_error`, so only the first duplicate key is reported and every other diagnostic in the file is suppressed.

11. **Bidi classifier omits the Arabic-Number class → weakened Trojan-Source / confusable detection** · cross-file (`unicode/tokenizer.ex` ⇄ `unicode/security.ex`) · [`CSCAN-cluster-bidi-dir-omits-arabic-number-class`](./CLUSTER_unicode.md#cscan-cluster-bidi-dir-omits-arabic-number-class) (+ per-file [`CSCAN-tokenizer-dir-nonascii-digit-weak`](./unicode-tokenizer.ex.md#cscan-tokenizer-dir-nonascii-digit-weak), [`CSCAN-security-unbidify-number-run-reversed`](./unicode-security.ex.md#cscan-security-unbidify-number-run-reversed)) · **Medium**, medium/high, verified. `dir/1` classifies only ASCII `48..57` as `:weak_number`; Arabic-Indic digits (bidi class `AN`, valid identifier chars) fall through to `:ltr` and terminate/reverse RTL runs, and `unbidify/1` additionally misses the UAX #9 L2 second reversal for multi-digit numbers. The resulting bidi skeleton diverges from display order, so confusable/Trojan-Source pairs can silently escape the (warning-only) lint. Security-relevant.

12. **`DateTime.from_map/1` drops `:calendar` → silent data corruption** · `lib/calendar/datetime.ex` · [`CSCAN-datetime-from-map-drops-calendar`](./lib-calendar-datetime.ex.md#cscan-datetime-from-map-drops-calendar) · **Medium**, high, verified. `convert/2` and `truncate/2` coerce non-ISO datetimes to `Calendar.ISO` while keeping the original calendar's numeric fields.

13. **`Dict.empty/1` delegates to a nonexistent function** · `lib/dict.ex` · [`CSCAN-dict-empty-undefined-delegate`](./lib-dict.ex.md#cscan-dict-empty-undefined-delegate) · **Medium**, high, verified. Delegates to `Map.empty/1`/`Keyword.empty/1`, which don't exist — every call raises `UndefinedFunctionError`.

14. **`Macro.pipe/3` emits structurally invalid AST for `Access.get`** · `lib/macro.ex` · [`CSCAN-macro-pipe-access-get-malformed-ast`](./lib-macro.ex.md#cscan-macro-pipe-access-get-malformed-ast) · **Medium**, high, verified. Captures the arg list instead of the whole `.` node; piping into an alias-expanded `Access.get` later fails to compile with an opaque error.

15. **`Stream.chunk/3` forwards `nil` leftover → opaque crash on uneven input** · `lib/stream.ex` · [`CSCAN-stream-chunk3-nil-leftover`](./lib-stream.ex.md#cscan-stream-chunk3-nil-leftover) · **Medium**, high, verified. 16. **`Regex.replace/4` crashes on non-numeric `\g{...}`** · `lib/regex.ex` · [`CSCAN-regex-g-brace-nonnumeric-crash`](./lib-regex.ex.md#cscan-regex-g-brace-nonnumeric-crash) · **Medium**, high, verified. `\g{name}`, `\g{}`, `\g{1` raise an unhandled `MatchError`/`ArgumentError` naming nothing actionable.

17. **`PartitionSupervisor.which_children/1` returns an out-of-spec `:undefined` after downscale** · `lib/partition_supervisor.ex` · [`CSCAN-partition_supervisor-which-children-undefined-shape`](./lib-partition_supervisor.ex.md#cscan-partition_supervisor-which-children-undefined-shape) · **Medium**, high, verified. 18. **`scripts/docs_config.exs` crashes on any non-semver git tag** · [`CSCAN-docs_config-tag-parse-crash`](./scripts-docs_config.exs.md#cscan-docs_config-tag-parse-crash) · **Medium**, high, verified.
